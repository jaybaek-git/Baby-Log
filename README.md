# 아기 기록 v1.0 — 사용설명서

## 구성
- `index.html` : 웹앱 (기록 버튼 · 24시간×7일 차트 · 목록 · 설정)
- `supabase_setup.sql` : 두 폰 동기화용 데이터베이스 설정
- `manifest.json`, `icon-180.png`, `icon-512.png` : 홈 화면 아이콘

## 1. Supabase 만들기 (5분)
1. supabase.com → Start your project → GitHub/Google로 가입
2. New project → Region: **Northeast Asia (Seoul)** → 생성
3. 왼쪽 **SQL Editor** → `supabase_setup.sql` 내용을 붙여넣기
4. `CHANGE-ME-우리가족-비밀코드-2026` 부분을 **우리만 아는 긴 코드**로 바꾸기 → **Run**
5. **Project Settings → API**(또는 Data API / API Keys)에서 확인
   - Project URL (예: `https://abcd.supabase.co`)
   - anon public key 또는 publishable key

> 무료 프로젝트는 7일 동안 사용이 없으면 일시정지돼요. 매일 쓰면 문제 없어요.

## 2. 웹에 올리기 (GitHub Pages)
1. GitHub 저장소에 `BabyLog` 폴더째 업로드 (index.html 등 4개 파일)
2. 저장소 **Settings → Pages** → Source: Deploy from a branch → `main` / `(root)` → Save
3. 1~2분 뒤 주소: `https://<아이디>.github.io/<저장소>/BabyLog/`

> 무료 GitHub Pages는 공개 저장소에서만 켜져요. 코드에는 키나 코드가 들어 있지 않아요(폰의 설정 탭에만 저장).

## 3. 아이폰에 설치 (두 분 모두)
1. 사파리로 위 주소 열기 → 공유 버튼 → **홈 화면에 추가**
2. 앱 열기 → **설정** 탭 → Project URL / API Key / 가족 코드 / 내 이름(아빠·엄마) 입력 → **저장 & 연결 테스트**
3. 오른쪽 위 점이 초록색 "동기화"면 완료

## 4. 잠금화면 버튼 (단축어)
설정 탭 아래 **잠금화면 단축어 설정값**에 값이 정리되어 있어요(복사 버튼).

1. 단축어 앱 → + → **URL 내용 가져오기**
   - URL: 설정 탭의 URL (한 번 탭 항목은 `add_event`, 시작/끝 항목은 `toggle_event`)
   - 방법: **POST**
   - 헤더: `apikey` = API Key  *(오류가 나면 `Authorization` = `Bearer <API Key>`도 추가)*
   - 요청 본문: **JSON** → `p_code` = 가족 코드, `p_type` = 항목 ID(예: `diaper`), (선택) `p_by` = 아빠
2. 이어서 **알림 보기** 동작 추가 → "기록됨"
3. 이름·아이콘 정하고 저장 → 잠금화면 하단 2칸 / 제어센터에 단축어 컨트롤로 추가

| 항목 | p_type | URL 끝 |
|---|---|---|
| 모유수유 (시작/끝) | breast | toggle_event |
| 분유 | formula | add_event (+ `p_value` = ml) |
| 기저귀 | diaper | add_event |
| 수면 (시작/끝) | sleep | toggle_event |
| 목욕 | bath | add_event |
| 체온 | temp | add_event (+ `p_value`) |
| 비타민 | vitamin | add_event |
| 터미타임 (시작/끝) | tummy | toggle_event |
| 기타 | etc | add_event |
| 기록A / 기록B | recA / recB | add_event |

> 대안: 단축어에서 **URL 열기**로 `.../BabyLog/?add=diaper` 를 열어도 앱이 열리면서 바로 기록돼요(앱 화면이 뜸).

## 5. 사용법
- **버튼 탭**: 바로 기록 → 아래 알림에서 메모(소변/대변, 왼쪽/오른쪽)·수정·취소
- **시작/끝 항목**(모유수유·수면·터미타임): 한 번 누르면 시작, 다시 누르면 끝
- **차트**: 세로 0~24시, 가로 7일. 좌우로 밀면 지난주. 표시를 탭하면 수정, 빈 곳을 탭하면 그 시각에 기록 추가. 범례를 탭하면 숨기기
- **설정 → 기록 버튼(메뉴)**: 목욕·체온·비타민·터미타임·기타·기록A·기록B 켜기/끄기, 이름·이모지·색·순서 변경, 새 항목 추가 → **메뉴 저장** (두 폰에 같이 적용)
- **데이터**: JSON 백업/불러오기, 엑셀용 CSV, 메모 앱 기록 가져오기

## v1.1 — 수유 알림 (웹 푸시)
모유수유·분유가 **끝난 시각**을 기준으로, 설정한 간격이 지나면 두 폰 모두에 알림이 와요.
- **자동 모드**: 기록이 24시간 이상, 간격 3개 이상 쌓이면 **최근 N일(기본 3일)** 기록의 보통 간격(중앙값, 끝→다음 시작)으로 알림 시각을 계속 다시 계산해요. 30분 안에 이어진 수유(모유 → 분유 보충)는 한 번으로 묶어요. 그 전에는 고정 간격을 써요.
- **고정 모드**: 설정한 간격(분)을 그대로 써요.
- **미리 알림**: 예상 시각보다 n분 먼저 알려 줘요.
- 수유 중(모유수유 시작만 누른 상태)에는 알림이 오지 않아요.

### 설정 순서
1. Supabase **SQL Editor**에 `supabase_v1.1_alarm.sql`을 붙여넣고 **Run**
2. 이어서 따로 받은 **키 입력 SQL**(VAPID 키 + 내 프로젝트 주소)을 **Run**
3. **Edge Functions → Deploy a new function → Via Editor** → 이름 `push` → `edge_function_push.ts` 내용 붙여넣기 → **Deploy**
4. 만든 `push` 함수 → **Details/Settings** → **Verify JWT** (JWT 검증) **끄기** → 저장
5. 두 폰 모두: 홈 화면 아이콘으로 앱 열기 → 설정 → **이 폰에서 알림 받기** → 허용 → **테스트 알림**

## v1.3 — 함께 기록 (목욕 → 기저귀 자동)
- 설정 → 기록 버튼 → 항목의 **함께 기록**에서 같이 남길 항목을 고르면, 그 버튼을 누를 때 함께 기록돼요 (기본: 목욕 → 기저귀, 메모 "목욕 때 함께")
- 잠금화면 단축어로 기록해도 같이 기록되게 하려면 Supabase SQL Editor에서 `supabase_v1.3_also_log.sql`을 한 번 실행하세요
- 백업 불러오기·메모 가져오기 때는 중복을 막기 위해 함께 기록이 동작하지 않아요

## v1.4 — 시간 되돌리기 · 수면 자동 종료 · 기저귀 별표
- 버튼을 누른 뒤 알림의 **⏪ 5분 전 / 10분 전 / 15분 전**으로 기록 시각을 바로 앞당길 수 있어요 (시작/끝 항목은 시작 또는 종료 시각)
- **누르면 끝내기**: 모유수유·분유·목욕·기저귀를 누르면 진행 중인 수면이 그 시각으로 자동 종료 (설정 → 기록 버튼에서 항목별 변경, 서버 SQL `supabase_v1.4_ends.sql`)
- **기저귀 별표**: 차트에서 기저귀는 ★ — 갈색 = 응가(대변·둘다), 하늘색 = 쉬야(소변), 파랑 = 메모 없음
- **연결 코드 붙여넣기**: 설정 → 연결에서 `BABYLOG|URL|KEY|가족코드|이름` 한 줄로 입력

## v1.5 — 되돌리기 / 다시 실행
- 화면 오른쪽 위 **↶ 되돌리기 / ↷ 다시 실행** — 기록 추가·수정·삭제·메모·시간 당기기를 순서대로 되돌리고 다시 적용 (최근 40개, 앱을 닫으면 초기화)
- 함께 기록(목욕→기저귀)·수면 자동 종료까지 한 번에 되돌려요

## v1.6 — 서버 자동 백업 · 시간 빠른 선택
- 서버가 **30분마다** 기록을 스냅샷으로 저장(바뀌었을 때만, 14일 보관) — 설정 → 서버 자동 백업에서 **이 시점으로** 복구 (복구 직전 상태도 자동 저장) · SQL `supabase_v1.6_backup.sql`
- 분유·체온 입력창과 기록 추가/수정 창의 시간 칸 아래에 **지금 / ⏪ 5·10·15분 전** 버튼
- 입력창을 열면 앞서 뜬 알림이 닫혀서 겹치지 않음

## v1.8 — 시간 기록 단위
- 설정 → **시간 기록 단위**: 1분(그대로) / 5분 반올림 / 10분 반올림 — 두 폰 공통, 버튼·단축어·직접 입력 모두 적용 (서버 SQL `supabase_v1.8_time_round.sql`)

## v1.9 — 끊김 없는 차트 · 체중 · 챙기기 알림
- 차트를 **좌우로 밀면** 과거 날짜가 자연스럽게 이어져요 (왼쪽 끝 근처에서 2주씩 자동으로 더 불러옴). **오늘 ▶**으로 바로 복귀
- 차트 아래 날짜별 요약에 **🌡 그날 마지막 체온**, **⚖ 그날 마지막 체중** 추가
